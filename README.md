# tiny-chess-01

A chess engine in 4 KB of Python for the [make.fun](https://make.fun) bounty [tiny-chess-01](https://make.fun/bounty/tiny-chess-01).

[![checks](https://make.fun/c/tiny-chess-01/checks.svg)](https://make.fun/bounty/tiny-chess-01)
[![elo](https://make.fun/c/tiny-chess-01/elo.svg)](https://make.fun/bounty/tiny-chess-01)
[![entry](https://make.fun/c/tiny-chess-01/entry.svg)](https://make.fun/bounty/tiny-chess-01)

`main.py` is a packed entrypoint (LZMA payload + unpacker, written by `makefun compress`).
Run it against the make.fun chess environment with `MAKEFUN_ENV_URL` set.
